# 09. Browse Stores — customers find YOU

🎬 **Flow + screen recording** — Flow makes the opener and closer; you record the app in the middle. Flow cannot render the real dashboard.

| | |
|---|---|
| **Audience** | Merchants + shoppers (dual purpose) |
| **Why this one** | Show the marketplace side. Good for shopper-side growth too. |
| **Length** | 18s |
| **Format** | 9:16 vertical, 1080x1920 |

---

## Hook (first 2 seconds — this decides everything)

> **Looking for something local? Start here.**

Most people watch with the sound off. The hook must be **on screen as text**,
big, in the first frame — not spoken.

## On-screen text timeline

```
  0:00  "Where do you shop when you want local?"
  0:04  "Browse Stores — by town."
  0:09  "Windhoek. Oshakati. Swakopmund."
  0:14  "oshicart.com/stores"
```

## Voiceover script

```
VO:
"Want to buy Namibian? Open Browse Stores.
 Filter by your town, see what's near you, tap a shop, order on WhatsApp.
 Every store on there is a real Namibian business."
```
