# 10. Put OshiCart on your home screen

🎬 **Flow + screen recording** — Flow makes the opener and closer; you record the app in the middle. Flow cannot render the real dashboard.

| | |
|---|---|
| **Audience** | Merchants and shoppers on Android/iPhone |
| **Why this one** | Drive daily habit. Home-screen icon = repeat use. |
| **Length** | 16s |
| **Format** | 9:16 vertical, 1080x1920 |

---

## Hook (first 2 seconds — this decides everything)

> **No Play Store download needed.**

Most people watch with the sound off. The hook must be **on screen as text**,
big, in the first frame — not spoken.

## On-screen text timeline

```
  0:00  "Want it on your home screen?"
  0:03  "No download. No Play Store."
  0:06  SCREEN: menu → Add to Home Screen
  0:12  "Opens like any app."
```

## Voiceover script

```
VO:
"You don't need to download anything.
 Open oshicart.com in your browser, tap the menu, choose Add to Home Screen.
 Now it opens like an app — no storage used, always up to date."

SCREEN RECORDING: Chrome menu → Add to Home Screen → icon appears → tap to open
```
