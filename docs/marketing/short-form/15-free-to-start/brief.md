# 15. Start free — no card, no catch

🎬 **Google Flow only** — no screen recording needed.

| | |
|---|---|
| **Audience** | Hesitant first-timers (retargeting) |
| **Why this one** | Close the loop. Lowest-friction CTA for retargeting ads. |
| **Length** | 15s |
| **Format** | 9:16 vertical, 1080x1920 |

---

## Hook (first 2 seconds — this decides everything)

> **Free plan. No card. Start today.**

Most people watch with the sound off. The hook must be **on screen as text**,
big, in the first frame — not spoken.

## On-screen text timeline

```
  0:00  "What does it cost to try?"
  0:03  "Nothing."
  0:05  "Free plan. No card needed."
  0:09  "Upgrade only when you're selling."
  0:12  "oshicart.com"
```
