# 04. Add your first product in 2 minutes

🎬 **Flow + screen recording** — Flow makes the opener and closer; you record the app in the middle. Flow cannot render the real dashboard.

| | |
|---|---|
| **Audience** | New merchants who signed up but stalled |
| **Why this one** | The activation moment. A store with no products earns nothing. |
| **Length** | 25s |
| **Format** | 9:16 vertical, 1080x1920 |

---

## Hook (first 2 seconds — this decides everything)

> **Your store is live but empty. Fix that in 2 minutes.**

Most people watch with the sound off. The hook must be **on screen as text**,
big, in the first frame — not spoken.

## On-screen text timeline

```
  0:00  "Your store is live… and empty."
  0:03  "Photo. Name. Price. Done."
  0:05  SCREEN RECORDING
  0:21  "Now customers can actually buy."
```

## Voiceover script

```
VO:
"A store with nothing in it can't be found and can't sell.
 Take one photo. Add the name and the price. Save.
 That's a product. Do five more and you have a shop."

SCREEN RECORDING SHOT LIST:
  1. Dashboard → Add Product
  2. Take/choose a photo (show the phone camera)
  3. Type name + price
  4. Save → product appears on the storefront
  5. Open the live store link to show it there
```
