# 06. Pay the Namibian way — EFT, eWallet, cash, PayToday

| | |
|---|---|
| **Audience** | Merchants worried customers can't pay |
| **Why this one** | Remove the 'my customers don't have credit cards' objection. |
| **Length** | 20s |
| **Format** | 9:16 vertical, 1080x1920 |

## Hook (first 2 seconds — this decides everything)

> **Your customers don't need a credit card.**

Most people watch with the sound off. The hook must be **on screen as text**,
big, in the first frame — not spoken.

## On-screen text timeline

```
  0:00  "'My customers don't have credit cards.'"
  0:03  "They don't need one."
  0:06  "EFT · eWallet · MTC Maris · Pay2Cell · PayToday · Cash"
  0:14  "They pay YOU directly."
```
